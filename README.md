# НарядAI — сердце системы: API, realtime и искусственный интеллект

Это бэкенд НарядAI — невидимый двигатель, который держит на себе весь завод: наряды, людей, фотографии, уведомления и искусственный интеллект. Фронтенд — красивая витрина, а здесь — правда: каждый статус проверяется, каждое действие записывается в неизменяемый журнал, каждое решение ИИ можно объяснить.

## Что он умеет

**Наряды со строгим характером.** Выдать, принять, начать, приостановить, завершить, закрыть, вернуть на доработку — у каждого перехода свои правила: кто может, из какого статуса, с какими полями. Причина отклонения — только из справочника, завершение — только с описанием работ и шифром, внеплан — только с фото «после». Схитрить через API не получится: сервер — финальный арбитр, а фронт лишь рисует разрешённые кнопки.

**ИИ, который работает даже без интернета.** Из коробки включён локальный движок: проверяет полноту отчёта, расход материалов против нормы, сроки, дубликаты фотографий и свежесть снимков. А если положить бесплатные ключи в `.env` — подключаются Gemini (сравнение фото «до/после» зрением), OpenRouter и Groq (включая расшифровку голосовых заметок). Наружу при этом уходят только обезличенные тексты — никаких имён, ПИНов и токенов. И главное: ИИ только советует, закрывает всегда человек.

**Живое производство в реальном времени.** Принял рабочий наряд — доска мастера обновилась сама. За это отвечают WebSocket, transactional outbox и фоновые воркеры: события не теряются, пропуски номеров отслеживаются, дедлайны мониторятся, а уведомления persistятся в базу (никаких внешних push-сервисов не нужно).

**Аналитика, которая находит боль.** Движок инсайтов сам замечает: оборудование ломается чаще нормы, после ППР идут отказы, ночная смена сыплет одним шифром, исполнитель выбивается из темпа. По каждому инсайту — уверенность, объяснение и кнопка «создать плановый наряд».

**Порядок в данных.** Справочники (участки, оборудование с QR, бригады, люди, шифры, материалы, нормы, причины), ПИН-авторизация с блокировкой после 5 попыток, роли с привязкой к участкам, мягкие удаления, аудит, идемпотентные мутации (повтор из офлайна не создаст дубль), приватное хранилище фото с подписанными ссылками, экспорт отчётов в PDF/XLSX.

## Технологии

Python, FastAPI, PostgreSQL (транзакции + неизменяемые журналы событий), Redis, S3-совместимое хранилище. Всё поднимается одной командой через Docker Compose — вместе с базой, очередями и эмулятором S3.

## Быстрый старт для разработчика

```sh
docker compose up --build   # API: http://localhost:8080, Swagger: /docs
```

Локальная разработка: `pip install -r requirements.txt` → `python -m scripts.migrate` → `python -m scripts.seed` (демо-завод: участки, люди, 500 нарядов) → `uvicorn app.main:app --reload`. Тесты: `pytest`.
