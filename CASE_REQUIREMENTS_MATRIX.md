# Требования кейса → реализация → доказательство

Сверено 14.10.2026 с предоставленным PDF «Кейс №1 Костанайские минералы рус (1)», все 8 страниц, и `MASTER_PROMPT_NaryadAI_Astra.md` (§1, 5–10). Схема десяти статусов проверена визуально; `cancelled` — дополнительная ветка реализации. Требования PDF не считаются доказательством наличия функции. Матрица описывает текущие локальные исходники и проверки, не состояние опубликованных доменов.

**Статусы:** `VERIFIED` — указанная часть фактически проверена в названной среде; `PARTIAL` — есть реализация/доказательство только части требования; `BLOCKED` — для приёмки отсутствует нужное устройство/сервис/доступ; `NOT RUN` — конкретное измерение или сценарий не выполнялся. Unit-тесты с fake DB не заменяют PostgreSQL, мобильный viewport — физический Android, наличие AI-адаптера — вызов модели. Процент «выполнения кейса» и будущие баллы жюри не вычисляются.
